PENDING QUESTIONS // 02 / 02

Details and actions

Only an Approved or Rejected row can be selected using the circle at the start of the row.

Tools – manage questionOpens the question's details and the available actions.
Question and answersCategory, complete question and four answers. The correct answer is the first, highlighted answer.
ReviewSubmission time, status and the reviewer's feedback.
MOVE
For approved questionsPlaces it in the first empty User question slot. It cannot be moved if no empty slot is available.
DELETE
For approved or rejected questionsPermanently empties the pending-question slot. This cannot be undone.
CLOSE
Without making changesCloses the details and leaves the question unchanged.

A Pending question cannot be selected or managed until the review has finished.
