ÚJ KÉRDÉS // 02 / 02

Legyen rövid, pontos és egyértelmű

Olyan kérdést írj, amelyet a játékos első olvasásra megért, és amelyre egyetlen biztosan helyes válasz adható.

01 // Egy világos kérdésNe zsúfolj több külön kérdést egy mondatba, és kerüld a félreérthető megfogalmazást.
02 // Ellenőrzött tényBeküldés előtt ellenőrizd a neveket, évszámokat, adatokat és a helyes választ.
03 // Rövid megfogalmazásNe nyújtsd szándékosan hosszúra a kérdést. A felesleges körítés csak nehezíti az olvasást.
04 // Hihető válaszokA három helytelen válasz is kapcsolódjon a témához, de egyik se lehessen szintén helyes.
05 // Helyes nyelvFigyelj a helyesírásra, az írásjelekre, valamint a könnyen olvasható mondatokra.
06 // Időtálló tartalomHa lehet, kerüld az olyan kérdést, amelynek helyes válasza rövid időn belül megváltozhat.
Nem küldhető be: sértő vagy trágár szöveg, személyes adat, szándékosan félrevezető állítás, illetve kitalált tény.
ElbírálásA beküldés nem jelent automatikus elfogadást. A kérdés csak jóváhagyás után kerülhet a Felhasználói kérdések közé.
F1 – a segítség újbóli megnyitása
