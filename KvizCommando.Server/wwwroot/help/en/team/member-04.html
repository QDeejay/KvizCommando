Understanding modifiers

Each row names the category to which the team member's modifier belongs.

OverviewAll current modifiers.
Favourable sideThe green modifiers.
Unfavourable sideThe red modifiers.
PrimaryChanges automatically with the character's rank and cannot be improved with development points.
SecondaryModifiers improved with the team member's own Sp.
ExtraAdditional modifiers improved with the team member's own Sp.
Green negative value: reduces the answer time calculated in battle. Red positive value: increases it. Selecting “Upgradable” opens the matching development page immediately. This option is unavailable at 0 vitality.
