How to build your loadout

You can change the complete loadout in a few simple steps.

1Open a row
Click the topic you want to change.
2Choose another topic
Click the topic you want in the list that appears.
3Continue if needed
You can change several rows before saving.
4Save it
Press the button with the disk icon. The button is available after you make a change.
If you do not save: changes made on this screen are not kept.
  • After saving, the final loadout appears immediately.
  • If a choice is no longer available, the affected row may be cleared.
  • If the setup cannot be saved, check the Own question rules and try again.
